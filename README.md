## Como instalar

1. **Crie src/components/ScrollBlurType.tsx** Copie o conteúdo de `src/ScrollBlurType.tsx` deste repositório.
2. **Sem dependências: só React e CSS inline.**
3. **Troque textos, imagens e cores pela sua marca.**
